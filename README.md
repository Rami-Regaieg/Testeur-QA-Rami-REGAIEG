# Portfolio QA / Support Applicatif

Portfolio personnel de Rami REGAIEG, orienté vers la qualité applicative, le support fonctionnel et le parcours e-commerce.

## Présentation

Ce projet est une landing page moderne et élégante destinée à présenter :

- le profil professionnel,
- les compétences en QA et support applicatif,
- les formations et parcours,
- les outils utilisés,
- les expériences clés,
- les moyens de contact.

Le site met en avant une identité visuelle sobre et premium avec des animations, un design de type portfolio éditorial et une navigation fluide.

## Stack technique

- HTML5
- CSS3
- JavaScript
- Police Google Fonts
- Icônes Font Awesome


## Fonctionnalités

- navigation fixe avec menu responsive,
- section hero immersive,
- présentation personnelle / storytelling,
- sections compétences, formations, expertise, outils et parcours,
- animations au scroll,
- curseur personnalisé,
- mise en page adaptée mobile et desktop.

## Prérequis

Aucun framework ni dépendance n'est requis pour lancer ce projet.

Il suffit d'avoir :

- un navigateur web moderne,
- un éditeur de code (optionnel).

## Propriété

Ce portfolio est conçu pour présenter le parcours professionnel et les compétences de Rami REGAIEG dans le domaine du QA, du support applicatif et du e-commerce.
